# EletricidadePro - Site de Eletricidade Profissional

Site profissional para empresa de eletricidade, desenvolvido com React 18 + Vite.

## 🚀 Instalação

```bash
# Navegar para a pasta do projeto
cd eletricidade-site

# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento
npm run dev

# Build para produção
npm run build

# Preview da build
npm run preview
```
